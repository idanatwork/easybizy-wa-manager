# WA Manager — ניהול וואטסאפ ללקוחות EasyBizy

קונסולה פנימית לניהול וואטסאפ של כל עסקי EasyBizy במקום אחד: לכל לקוח מפתח API משלו,
כתובת webhook משלו, בוטים, שיחות ויומן פעילות משלו.

- **`docs/`** — האתר הסטטי (עברית, RTL), מתארח ב-GitHub Pages. בלי שרת, בלי build step.
- **`worker/`** — Cloudflare Worker + D1: מקלט ה-webhooks, מנוע הבוטים וה-API. ראו `worker/README.md`.

## יכולות

- **לקוחות** — רשימת עסקים עם מצב חיבור, מספר וואטסאפ, דירוג איכות ואירוע אחרון; בדיקת חיבור חיה מול EasyBizy.
- **הגדרת לקוח** — API key/secret (מוצגים מוסווים), webhook ייחודי + סוד, ורשימת 10 האירועים עם סימון מה שהגיע בפועל.
- **בוטים** — טריגרים (מילות מפתח / כל הודעה / הודעה ראשונה / אירוע EasyBizy), צעדים: טקסט, כפתורים עם ענפים, קישור, קובץ, תבנית, שאלה, תנאי, פעולת EasyBizy, העברה לצוות. מודע לחלון 24 השעות של וואטסאפ.
- **שיחות** — תיבת דואר נכנס לכל לקוח, מענה כצוות, השהיית בוט לשיחה, שליחת תבנית כשהחלון סגור.
- **פעילות** — לוג מלא של כל webhook, מה רץ ומה נכשל, עם צפייה ב-payload המלא.

## אבטחה

הריפו והאתר ציבוריים, ולכן **אין בהם שום סוד**: מפתחות ה-API של הלקוחות נשמרים רק ב-D1
בצד ה-Worker, והכניסה לקונסולה מוגנת בסיסמת צוות. האתר עצמו גלוי לכולם אך חסר תועלת בלעדיה.
